## 3. 자동 테스트

`python -X utf8 -m pytest -q` 실제 실행 결과: **155 passed, 16 skipped, 0 failed (6.61초)**.

검증 범위:

- 공통 Tool 성공·실패 계약과 네트워크 예외 비노출
- 위치 모호성, 예보 시간대 변환, 공휴일 날짜 필터
- LangGraph 노드와 Tool 호출 순서
- Tool 결과 재사용과 재계획 상한
- 필수 제약 확인 실패 시 일정 생성 차단
- 메모리 격리와 조건 갱신
- 계획 CRUD와 시간 겹침 경고
- 로그 저장·조회·삭제와 수정 경로 부재
- FastAPI 요청 검증과 오류 상세 비노출
- 분리 프론트엔드 API 연동

로컬 FR-E800 SQLite·Chroma와 Qwen 모델 파일은 Git 정책에 따라 작업 공간에 없었다. 따라서 데이터·모델이 필요한 16개 테스트는 건너뛰며 실제 RAG/LLM 추론을 실행했다고 보고하지 않는다. `ManualSearchTool`의 페이지 보존, `NO_INDEX`, 어댑터 동작은 자동 테스트로 확인했다. 인사·사용법·컨텍스트 없는 안내는 매뉴얼 DB 없이도 처리하도록 기존 RAG 저장소 초기화를 지연시켰다.

- 계획: UI에서 계획 생성 후 목록이 1건으로 즉시 갱신됨을 확인
