# 검색 지표와 검증 범위

2026-10-27 기준. 기존 검색 평가 결과와 실패 질의를 재검토하고, 자동 테스트를 다시 실행한 기록이다. 검색 알고리즘·인덱스·평가 문항은 변경하지 않았다.

## 검색 적중률

| 항목 | 결과 | 기준 |
|---|---|---|
| Hit@1 | 7/10, 70% | 정답 코드가 코드 후보 1위에 위치 |
| Hit@3 | 9/10, 90% | 정답 코드가 코드 후보 상위 3개에 포함 |

40문항은 코드 질의 10개, 자연어 질의 15개, 복합 질의 10개, 미등록 코드·근거 부족 질의 5개로 구성된다. 위 검색 지표의 대상은 자연어 질의 15개 중 정답 코드가 있는 10개다. 나머지 5개는 코드가 없는 증상 표를 정답으로 사용하므로 코드 적중률에서 제외한다.

검색된 청크에서 코드가 없는 결과를 제외하고, 코드 중복을 제거한 순위로 계산한다. 서비스의 청크 상위 3개와 평가의 코드 상위 3개는 같은 단위가 아니다. 해당 수치를 전체 질문의 답변 정확도로 해석할 수 없다.

Hit@1은 저장된 동일 평가 결과의 첫 번째 코드 후보를 정답 코드와 다시 대조해 산출했다. 기존 결과의 Hit@3 90%를 대체하거나 개선한 수치가 아니다. [기존 검색 평가](local_llm/chat_regression/REPORT.md)

## 부족 전압 질의의 검색 실패

- 문항: n07, 전원 전압 저하와 부족 전압 보호 기능에 관한 자연어 질의.
- 정답: E.UVT.
- 코드 후보 상위 3개: E.10, E.MB1, E.MB3.
- 기존 인덱스를 읽어 다시 검색한 E.UVT의 위치: 코드 후보 41위, 청크 55위.

E.UVT 원문은 SQLite와 ChromaDB에 존재한다. 원문 누락이 아니라 검색 순위 문제다. 현재 단일 E5 벡터 유사도 검색에서는 이 문항의 부족 전압 표현보다 다른 알람의 일반적인 출력 정지 문장이 높은 순위에 놓였다. 이 관찰만으로 임베딩 내부의 오류 원인을 확정하지는 않는다.

명칭·핵심 용어 일치의 반영, 검색 후보 재정렬, 청크 구성 비교가 개선 후보에 해당한다. 개선 효과는 아직 측정하지 않았다. n07 한 문항의 특수 처리나 기존 10문항에 맞춘 조정으로 일반적인 성능 향상을 주장해서는 안 된다.

## 최종 답변 관련성의 한계

현재 증상 검색은 여러 관련 후보의 상세 원문을 함께 제공한다. 정답 코드가 상위 3개에 포함되더라도 다른 코드의 항목이 답변에 섞일 수 있다. 저장된 원문 검색 모드의 필수 항목 진단은 40건 중 28건을 통과했으며, 12건에 누락·예상 외 레코드·근거 부족 처리 등의 실패 플래그가 있다. 이 수치는 실제 LLM 답변 정답률이 아니다.

원문 인용·페이지 검증은 검색된 자료를 정확히 표시했는지 검사한다. 그 자료가 질문에 적합한지까지 보장하지는 않는다. 검색 후 관련성 선별과 의미적 답변 평가는 별도로 보완해야 한다.

## 자동 테스트

재실행 결과: 전체 136개 중 통과 136개, 실패 0개, 오류 0개, 건너뜀 0개. pytest 출력 기준 소요 시간은 24.92초다. JUnit은 로컬 `logs/evaluation-audit-tests.xml`에 보존했다.

| 검사 범위 | 케이스 수 |
|---|---:|
| PDF·구조화 데이터 검증 | 5 |
| 검색·근거·답변 계약 | 24 |

136은 개발자가 작성한 검사와 매개변수 조합의 수다. 일부 검사는 의도된 실패 응답과 오류 처리가 정상적으로 작동하는지 확인한다. 모의 LLM·HTTP 검사도 포함되므로, 이 결과를 실제 LLM이 136개 질문에 정답을 생성한 기록으로 해석할 수 없다.

## 미완료 항목

1. 검색 관련성 개선: 부족 전압 질의의 검색 실패와 예상 외 알람의 동시 출력 개선.
2. 전체 40문항의 실제 Qwen3 답변 평가: 필수 항목 검사와 수동 관련성 검토를 함께 수행한 정답률 산출.
3. 독립 평가 세트 확보: 현재 40문항은 개발용으로 작성한 문항이며, 학습·조정에 사용하지 않은 외부 평가 세트는 없다.
4. 다회차 대화 품질 평가: 방별 격리와 맥락 연결 동작은 검사했으나, 실제 LLM을 사용한 다양한 대화의 정답률은 미측정이다.
5. 응답 시간 반복 측정: 실제 LLM을 포함한 예열·비예열 조건별 p50/p95는 미측정이다. 기존 개별 응답 시간은 반복 벤치마크를 대체하지 않는다.
